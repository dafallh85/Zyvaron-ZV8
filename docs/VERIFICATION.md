# Zyvaron Verification Framework

## Overview

Zyvaron aims to maintain clear separation between verified technical information, project-provided information, and future plans.

## Verification Categories

### Verified

Information supported by reliable blockchain or technical evidence.

### Confirmed

Information confirmed through an appropriate authoritative source.

### Reported

Information provided by the project or another source but not independently verified.

### Unverified

Information for which sufficient evidence is not currently available.

### Not Available

Information that cannot currently be determined.

### Under Review

Information currently being examined or validated.

## Blockchain Verification

Where applicable, technical information may be checked against public blockchain data and verified smart contracts.

Examples include:

- Contract address
- Token supply
- Decimals
- Ownership
- Contract permissions
- Transactions
- Token balances
- Contract verification status

## Project Information

Information supplied by Zyvaron should be clearly distinguished from independently verified blockchain data.

## Updates

Asset information may change over time.

Zyvaron documentation should be updated when reliable new information becomes available.

## Transparency Principle

Zyvaron should never present assumptions or future plans as confirmed technical facts.
