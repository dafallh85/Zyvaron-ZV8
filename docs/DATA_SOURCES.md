# Zyvaron Data Sources

## Overview

Zyvaron documentation may use blockchain data, technical documentation, and project-provided information.

## Primary Sources

Where applicable, information may be obtained from:

- Public blockchain data
- Verified smart contracts
- Ethereum blockchain explorers
- On-chain transactions
- Token contract interfaces
- Official Zyvaron documentation
- Official project announcements
- Official project channels

## Source Priority

When multiple sources are available, priority should generally be given to:

1. On-chain data
2. Verified contract information
3. Official technical documentation
4. Official project information
5. Other publicly available information

## Source Transparency

Important information should identify its source whenever practical.

Project-provided information should not automatically be presented as independently verified.

## Data Changes

Blockchain and project information may change over time.

Documentation should be updated when reliable new information becomes available.

## Limitations

Zyvaron does not guarantee that all information is complete, permanent, or error-free.

Users should independently verify critical information before interacting with digital assets.
